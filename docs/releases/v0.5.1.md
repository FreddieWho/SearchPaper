# SearchPaper v0.5.1 Release Notes

Release date: 2026-07-10

## Summary

SearchPaper v0.5.1 is a maintenance and documentation release focused on agent
integration polish. It fixes a deterministic skill-loading warning, refreshes
the English and Chinese READMEs, and adds a generated project banner.

## Fixed

- Added required YAML frontmatter to all repository `SKILL.md` files:
  - `.agents/skills/literature-search/SKILL.md`
  - `.opencode/skills/literature-search/SKILL.md`
  - `.claude/skills/literature-search/SKILL.md`
- Updated the shared integration template so generated OpenCode skills keep
  valid `name` and `description` frontmatter.
- Split skill content from Codex/Claude instruction content so instruction
  scaffolds remain plain Markdown.
- Added regression assertions for repository skill frontmatter.

## Documentation

- Reworked `README.md` and `README.zh.md` for faster scanning.
- Added tables for sources, workflows, MCP tools, agent installation, and
  failure modes.
- Added `docs/assets/searchpaper-banner.png` as the README header banner.
- Fixed malformed README code fences around configuration examples.
- Corrected the Chinese README environment variable spelling to
  `OPENALEX_EMAIL`.

## Validation

  `---`.

No migration is required. Restart Codex/OpenCode/Claude after updating so agent
skill discovery and MCP configuration are reloaded.
